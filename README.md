## Projects

### Personal projects

- [**Vehicle Maintenance Tracker**](https://github.com/pwiseley/vehicle-maintenance-tracker) -> Fleet maintenance API in C#, built and shipped end to end.
- [**URL Shortener**](https://github.com/pwiseley/url-shortener) -> Link shortener with click analytics and a full CI/CD pipeline.
- [**Insurance Quote Calculator**](https://github.com/pwiseley/insurance-quote) -> Spring Boot quote engine modeling policy types via JPA inheritance.
- [**Toastmasters Platform**](https://github.com/pwiseley/ToastmastersFSA-app) -> Club management system with scheduling and async email/PDF generation.

### Team projects

- [**UTasks**](https://github.com/pwiseley/UTasks-app) -> Trello-like task manager with drag-and-drop boards and real-time chat.
- [**Floppa Marketplace**](https://github.com/pwiseley/Floppa-app) -> Marketplace REST API in Java/Jersey with TDD and a Docker/GHCR pipeline.
- [**UFood**](https://github.com/pwiseley/UFood-app) -> Restaurant discovery platform with map-based search and favorites.
- [**Smart City - Autonomous Delivery Robots**](https://github.com/pwiseley/SmartCity-DeliveryRobot) -> ROS2 rover navigating a smart city to transport goods autonomously.
- [**HeatMyFloor**](https://github.com/pwiseley/HeatMyFloor-app) -> Java desktop app modeling heated floor wire paths from constraints.
- [**ULaval Parking**](https://github.com/pwiseley/ULavalParking-app) -> UI/UX design for a parking permit app across 4 device formats.
